## Contrato fechado (buracos mecânicos do mapa)

O mapa dá a tabela de eventos e os headers. Isto não reabre decisão — só impede o implementer de inventar formato:

1. **Caminho de `sse-format.ts`:** `web/src/app/api/stream/sse-format.ts` (colado na rota). Não vai para `lib/` — o cliente nunca formata SSE.
2. **`formatSse(event, data?)`:**
   ```ts
   export function formatSse(
     event: "reading" | "ping" | "reset",
     data = "",
   ): string;
   ```
   Corpo: `` `event: ${event}\ndata: ${data}\n\n` ``. Sem campo `id:`. Sem `retry:`. Sem comentário `: ping`.
3. **`reading`:** segundo argumento = `JSON.stringify(reading)` (uma linha, sem `JSON.stringify(..., null, 2)`). A rota é quem stringify; `formatSse` só envelopa.
4. **`ping` e `reset`:** omitir o segundo argumento → `data` vazio. Frame resultante: `"event: ping\ndata: \n\n"` (espaço depois de `data:`; o EventSource descarta esse espaço e entrega `""`).
5. **Ping a cada 15 s, não no connect.** `setInterval(..., 15_000)` — o primeiro `ping` sai em t=15 s, não em t=0. Sem ping imediato “pra aquecer”.
6. **Sem histórico no connect.** Não chame `getRecentReadings`. `watchReadings` já semeia o offset sem emitir (W2). Se a rota mandar um `reading` sozinha, o teste “stream vazio até alguém emitir” quebra.
7. **Um watcher por conexão.** `watchReadings(...)` dentro de `start()`, não no topo do módulo. Cada `GET` tem o próprio interval de ping e o próprio `stop`. Sem singleton (W5 também vai chamar `watchReadings` separado).
8. **Cleanup:** `request.signal` abortado **ou** `cancel()` do stream → chama o `stop` de `watchReadings` **e** `clearInterval` do ping. Flag `closed` para não dar `enqueue`/`close` duas vezes (enqueue depois de close joga e derruba o process).
9. **Runtime:** `export const runtime = "nodejs"` — `watchReadings` usa `fs`. Não use Edge. Não exporte `dynamic` (Next 16: a `Response` com stream já é request-time; `force-dynamic` é ruído).
10. **Headers:** os três do mapa, nada mais. Sem `X-Accel-Buffering`. Sem `charset=utf-8` extra. Sem `id` no body.
11. **Só `GET`.** Não exporte `POST`/`PUT`. Não crie `web/src/app/api/report/`.
12. **Apagar `web/src/app/api/README.md`.** A pasta `stream/` é a documentação da camada. Não crie outro README.
13. **Testes da rota mockam `watchReadings`.** Não leem `daily-report.csv` da raiz. Não usam fake timers no `sse-format.test.ts` (é função pura). Fake timers só em `route.test.ts`.

```ts
import { watchReadings } from "@/services/report/report-service";

import { formatSse } from "./sse-format";

export const runtime = "nodejs";

const PING_MS = 15_000;

const SSE_HEADERS = {
  "Content-Type": "text/event-stream",
  "Cache-Control": "no-cache, no-transform",
  Connection: "keep-alive",
};

export async function GET(request: Request) {
  const encoder = new TextEncoder();
  let shutdown = () => {};

  const stream = new ReadableStream({
    start(controller) {
      let closed = false;

      const send = (frame: string) => {
        if (closed) return;
        controller.enqueue(encoder.encode(frame));
      };

      const stopWatch = watchReadings({
        onReading: (reading) =>
          send(formatSse("reading", JSON.stringify(reading))),
        onReset: () => send(formatSse("reset")),
      });

      const pingId = setInterval(() => send(formatSse("ping")), PING_MS);

      shutdown = () => {
        if (closed) return;
        closed = true;
        stopWatch();
        clearInterval(pingId);
        try {
          controller.close();
        } catch {
          // already cancelled
        }
      };

      request.signal.addEventListener("abort", shutdown, { once: true });
    },
    cancel() {
      shutdown();
    },
  });

  return new Response(stream, { headers: SSE_HEADERS });
}
```
